# feuerwehr-funkuebung
Feuerwehr-Funkübungen: Realistische und fachlich korrekte Übungen für Einsatztraining in Niedersachsen

## Verfügbare Funkübungen

### Vegetationsbrandbekämpfung

Ordner: [`funkuebungen/vegetationsbrand`](funkuebungen/vegetationsbrand)

- `funksprueche.txt` – 50 Funksprüche (je Zeile ein Spruch, buchstabierpflichtige Begriffe zwischen `**` markiert)
- `funksprueche.xlsx` – gleiche 50 Funksprüche in einer Excel-Tabelle, Spalte „Funkspruch“, buchstabierpflichtige Begriffe fett und in Großbuchstaben formatiert

Die Übung beginnt unmittelbar nach dem Eintreffen an der Einsatzstelle und bildet einen zusammenhängenden, in der Schwierigkeit ansteigenden Einsatzverlauf zur Bekämpfung eines ausgedehnten Vegetationsbrandes mit mehreren Einsatzabschnitten, Nachalarmierungen und Wasserversorgung über weite Förderstrecken ab.
